# Legacy v1.1 prototype (preserved)

The original single-file prototype (`big_guard_v1.py`, `run_demo_v1.py`, test) from
`BIG-Guard-Attractive-Dashboard.zip`. It was renamed because a `big_guard.py` module
would clash with the new `big_guard/` package. The new engine supersedes it; the
dark SOC theme and card styling of the old dashboard were carried over to `big_guard/ui/theme.py`.
